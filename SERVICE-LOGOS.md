# Service logo sources

Official artwork is bundled locally for identifying the supported integrations. Brand ownership remains with the respective service; these assets are not original GPL artwork.

- Eagle: https://eagle.cool/images/home-cta-logo.png (linked on https://eagle.cool/)
- Feishu: https://p1-hera.feishucdn.com/tos-cn-i-jbbdkfciu3/84a9f036fe2b44f99b899fff4beeb963~tplv-jbbdkfciu3-image:100:100.image (official homepage og:image)

Displayed with a shared SVG blue tonal filter and uniform icon containers. No runtime requests to the brand sites.

Toolbar variant: Feishu uses the original transparent silhouette in white. Eagle uses a red-channel luminance mask to remove the blue app tile and show the light bird shape in white. Source images remain embedded unchanged.

Panel Eagle icon now uses the untouched circular emblem from https://eagle.cool/images/logo.png, via SVG viewBox 0 16 64 64 (wordmark excluded). Original gradient and feather details are preserved; toolbar white silhouette unchanged.
