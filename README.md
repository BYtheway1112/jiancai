# 简采 · 小红书与抖音作品采集

![简采 Logo](./logo.svg)

简采是一个自用 Chrome 扩展，用紧凑的页面入口采集小红书与抖音的单条作品和博主主页作品。数据先保存在浏览器本地，可导出 Excel、同步到飞书多维表格，也可以把图文图片或原视频连同标题、完整文案、作者、标签和来源链接直接归档到 Eagle。

## 功能

- 小红书：图文和视频作品采集，图文支持下载当前显示图片或整组图片。
- 抖音：视频和图文作品采集，图文支持下载当前显示图片或整组图片。
- 主页批量采集：当前已加载、指定数量、全部公开可访问作品；串行执行并可停止。
- Excel：小红书/抖音按图文与视频分别输出工作表，保留完整正文、链接和采集时间。
- 飞书多维表格：按平台与作品类型选择目标表，自动补齐映射列；单个附件超过 20 MiB 或无法确认大小时保留链接并跳过附件。
- 抖音合集：在作品页“更多”中按合集顺序串行采集到飞书，支持进度、停止、去重更新和图文/视频自动分表；合集名称写入“所属合集”，原合集 Excel 导出保留。
- Eagle：按作品类型自动选择原视频或有序图片，写入标题、完整文案、作者、话题/标签、来源链接和完整采集字段，并保留与飞书入库一致的来源文案、检索摘要和核对说明。

## 本地安装

1. 安装 Node.js 18 或更高版本和 pnpm。
2. 安装依赖并构建：

   ```bash
   pnpm install
   pnpm build
   ```

3. 打开 Chrome 的 `chrome://extensions/`，启用开发者模式，点击“加载已解压的扩展程序”，选择 `output/chrome-mv3`。
4. 在扩展的“采集列表 / 设置”中按需填写自己的飞书应用凭证和目标多维表格；凭证只保存在本机扩展存储中。
5. 使用 Eagle 功能时保持 Eagle 桌面应用运行，并在设置中选择目标资源库和文件夹。

## 隐私边界

简采没有自建服务器、会员系统、广告或行为分析。页面数据只在用户主动点击采集、同步、下载或导入时处理；本地列表、Excel、下载文件和 Eagle 素材由用户自己控制。飞书凭证不会注入社交网站页面，也不会写入源码或导出文件。请在使用前阅读 [隐私政策](./PRIVACY.CN.md)。
